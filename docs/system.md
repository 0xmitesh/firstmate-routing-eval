# Evaluation Application

This repository contains a deliberately small commerce-domain TypeScript
application used to evaluate multi-agent software-development workflows.

Current domains:

- catalogue filtering
- inventory reservations
- authorization
- Google-resource parsing

The baseline must remain deterministic, dependency-light, and fully tested.

Evaluation tasks may add features, introduce architectural changes, investigate
bugs, perform reviews, or refactor individual domains. Independent tasks should
be capable of being worked on in isolated worktrees.
